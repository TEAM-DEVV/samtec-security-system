# @samtec/web

The SAMTEC dashboard: a React 19 single-page app built with Vite 8, Tailwind CSS 4 and shadcn/ui.

- **Guide:** [Frontend guide](../../docs/guides/03-frontend-guide.md)
- **Where its data comes from:** the API contract in [packages/contracts](../../packages/contracts), through `$api` in `src/lib/api.ts`

## Commands

Run these from the repository root.

| Command | What it does |
|---|---|
| `pnpm dev:web` | Dashboard with mock data on http://localhost:5173 |
| `pnpm dev:web:live` | Dashboard calling the real API on http://localhost:3000 |
| `pnpm --filter @samtec/web test` | Runs the dashboard tests |
| `pnpm --filter @samtec/web build` | Builds the production files into `dist/` |

## Notes

- `src/components/ui/` holds shadcn/ui components. Biome skips this folder, so the components can be updated with the shadcn CLI without style conflicts.
- `public/mockServiceWorker.js` is generated by MSW. After upgrading MSW, regenerate it with `pnpm --filter @samtec/web exec msw init public --no-save`.
- The colour theme lives in `src/index.css` (CSS variables for light and dark mode).
